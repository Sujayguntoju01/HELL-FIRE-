# HELL FIRE — Game Development Project

## Project Overview
HELL FIRE is a browser-based arena shooter prototype built as a game development project. It is designed to demonstrate front-end game interaction and a Node.js real-time multiplayer foundation.

## Features
- Single-player arena mode with AI opponents
- Multiplayer rooms using room codes
- Mouse aiming and firing controls
- Obstacles and arena collision mechanics
- Bombs and collectible pickups
- Points-based bullet upgrades
- Responsive HTML/CSS interface

## Technologies
- JavaScript
- Node.js
- Express.js
- Socket.IO
- HTML5
- CSS3

## Run Locally
1. Install Node.js.
2. Extract this project folder.
3. Open a terminal in the folder containing `package.json`.
4. Run `npm install`.
5. Run `npm start`.
6. Open `http://localhost:3000` in your browser.

## Project Status
This is a development prototype. Features may need further testing and refinement before public deployment. Multiplayer requires a compatible Node.js host with WebSocket support to be available online.
